# TechStore — متجر الهواتف

مشروع لعرض مهارات تطوير متجر إلكتروني متكامل باستخدام **PHP وMariaDB وPDO**، بواجهة عربية متجاوبة من اليمين إلى اليسار.

![الرئيسية](screenshots/00-cover.png)

## ماذا يقدم المشروع؟

تصفح 18 منتجًا من 5 ماركات، وابحث وفلتر حسب الماركة والعروض، واطّلع على المواصفات، ثم أضف إلى السلة وأكمل طلبًا بالدفع عند الاستلام. لوحة المدير تتيح إدارة المنتجات ومواصفاتها والطلبات والمستخدمين، وتعرض إحصاءات فعلية من القاعدة.

الأسعار للعرض فقط. الطلبات المرفقة وهمية، ولا توجد حسابات أو كلمات مرور افتراضية أو بيانات عملاء حقيقية داخل المستودع.

## التشغيل على Windows

يتطلب XAMPP داخل `C:\xampp`، مع إضافات PHP: `pdo_mysql` و`mbstring` و`curl` للاختبارات.

```powershell
.\Initialize-Store.ps1
```

افتح `http://127.0.0.1:8000/`، ثم أنشئ حساب المدير ببريدك:

```powershell
C:\xampp\php\php.exe tools\setup-admin.php your-email@example.com
```

تُحفظ كلمة مرور عشوائية في `.runtime/admin-login.txt`، خارج مجلد الويب وخارج Git. لا ترفع هذا الملف.

في المرات التالية:

```powershell
.\Start-Store.ps1
```

لنسخة احتياطية خاصة:

```powershell
.\Backup-Store.ps1
```

## اختبار المشروع

```powershell
C:\xampp\php\php.exe tests\smoke.php
```

آخر نتيجة: **69 فحصًا ناجحًا**. تنشئ الاختبارات سجلات مؤقتة ثم تنظفها؛ شغّلها على قاعدة التطوير المحلية.

## سيناريو عرض مقترح — 3 دقائق

1. ابدأ بالرئيسية، ثم اعرض ماركات الهواتف والفلاتر المركبة.
2. افتح منتجًا لشرح المواصفات، وأضفه للسلة وغيّر كميته.
3. أكمل طلبًا ببيانات تجريبية، ثم اعرض الفاتورة القابلة للطباعة.
4. ادخل بحساب المدير واعرض الإحصاءات والطلبات وتغيير الحالة.
5. اعرض تعديل منتج وحفظ الوصف والشاشة والبطارية.

## النشر على GitHub

فك ملف ZIP وارفع **محتويات مجلد `TechStore`** إلى مستودع جديد. سيعرض GitHub ملف README والصور تلقائيًا. رفع الكود إلى GitHub لا يشغّل موقع PHP؛ الهدف هنا عرض المشروع ومصدره.

الملف المضغوط يستبعد `.runtime` والنسخ الاحتياطية والسجلات والملفات الخاصة. لا تضفها يدويًا.
